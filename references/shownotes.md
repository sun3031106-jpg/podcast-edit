# Show Notes 写作规范（神灵有感）

输入：成片逐字稿 docx（带"发言人X 时间戳"）。参考往期 show notes 的文风。
输出：show notes docx，放在逐字稿同目录，文件名 `神灵有感-{主题}-shownotes.docx`。

## 结构

```
标题：
1、{备选标题1}
2、{备选标题2}
3、{备选标题3}

{开头第1段：一串读者好奇的问题}
{开头第2段：这期可能和你想象的不太一样——新角度}
{开头第3段：聊什么 + 预告精彩故事}
{开头第4段：不管你……，希望这期能……}

{时间戳} {降落点文案}
……

{一句口语化祝福，带～}
```

## 开头介绍

- 文字版**不写**"欢迎来到神灵有感""第X期"、主持人个人经历——那些是语音里用的
- 用问题开场，引起好奇；再给出"和你想象的不太一样"的角度
- 少用"我们会……""这一期我们想聊……"，直接说内容
- 段落写完整，不要一句一段
- 反复点出本期核心关键词（如风水那期的"科学"）

## 标题

- 给 3 个，编号 `1、2、3、`
- 多用问句和悬念，不直接下结论（"风水，是科学还是玄学？"而不是"风水不是玄学"）
- 同一个标题里不重复用词

## 时间戳降落点

- 相邻间隔 ≤ 5 分钟，一般 3–4 分钟；故事密集处可以更密
- 时间戳取该话题在逐字稿里的起始时间
- 文案要有钩子：问句、反常识、悬念、"敲重点！"、"你敢信？"、"教你……"
- **只埋钩子，不剧透**：不写答案、不写具体细节
- 相邻两条句式不重复

## 红线

- 不否定、不得罪人：不写"XX没用""运差摆啥都白搭""风水师说尽量调就是心理作用"
- 敏感/负面场景（殡仪馆、凶宅、破产、被调查）不直接写，换成"千万要避开的坑""惊险时刻"
- 嘉宾性别不确定时称"小师傅"，不用代词

## 定稿范例（家居风水，2026-09）

标题：
1、门口摆貔貅没用？科学派风水师的选房避坑指南
2、罗盘乱转、瞬间裂开……租房买房前，先听这一期
3、风水，是科学还是玄学？选房这件事，选择真的大于努力

说到风水，你是不是也有很多好奇？大门对着电梯到底好不好？家里摆个貔貅、聚宝盆，真的能招财吗？别人口中那些玄之又玄的说法，到底有几分道理？作为普通人，买房、租房的时候又该怎么看？

这一期聊的风水，可能和你想象的不太一样。一位"科学派"的风水师会告诉你：风水并不是玄学，它讲的是环境对人的影响——有看得见的光、声音、空气，也有看不见的磁场和能量。它们怎样一点点影响一个人的状态和选择，都能找到很科学的解释。

从什么是好风水、什么是坏风水聊起，聊风水里科学的部分，聊环境对人的影响，也聊在买房、选房之前，普通人自己就能用上的看房方法。中间还有两段小师傅看风水时遇到的惊险时刻。

不管你是正在租房、准备买房，还是想让现在的家住得更舒服，希望这期能帮你多一双看房的眼睛。
